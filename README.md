# SNHU-360
The goal of the app I developed was to help users manage and track inventory items in a simple and organized way. The main user need it addressed was being able to quickly add, view, and update items without confusion. This is useful for small businesses or personal tracking where keeping things organized is important.

The app included screens like login, registration, and the main inventory screen. The main features were adding items, viewing a list of items, and updating or deleting them. I designed the UI to be simple, with clear labels and spacing so users could easily understand what to do. I tried to keep everything easy to find so users wouldn’t get lost, which made the design more user-friendly.

When coding the app, I used a step-by-step approach. I started with the basic structure, then added features one at a time and tested each part as I went. I also kept my code organized by separating different parts like activities and layouts. This strategy made it easier to fix problems and could be used in future projects to stay organized and efficient.

To test my code, I ran the app in the emulator and checked each feature to make sure it worked correctly. I tested things like logging in, adding items, and making sure the app didn’t crash. Testing is important because it helps catch errors early and makes sure the app works as expected. It also showed me where I needed to fix bugs or improve functionality.

One challenge I had was getting all the screens to connect properly and making sure the app opened on the correct screen. I had to adjust the manifest and activity flow to fix this, which helped me understand how navigation works in Android apps.

I think I was most successful in building the overall structure of the app and making it functional. I was able to connect different parts of the app and create a working system that meets the user’s needs, which shows my understanding of both design and development.
